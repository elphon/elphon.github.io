# ============================================================================
# photo_sections / photo_groups 작성 레퍼런스
# ============================================================================
# 이 아래는 사진 배치용 DSL처럼 사용한다.
# `photo_sections`에 적은 순서가 실제 페이지의 섹션 순서이며, 같은 photo id는 전체에서 한 번만 사용한다.
# 사진 배치는 기본적으로 직접 지정(manual)하고, 4장 wide 레이아웃에서만 `order: "auto"`를 선택적으로 쓴다.
#
# ---------------------------------------------------------------------------
# 0. section에서 사용할 수 있는 공통 키
# ---------------------------------------------------------------------------
# - `group`   : 선택. `photo_groups[].id`와 연결한다.
#               같은 group이 연속되면 하나의 챕터 박스 안에 여러 section이 묶인다.
#               생략하면 해당 section은 챕터 박스 밖에서 단독으로 렌더링된다.
# - `type`    : 선택. 일반 사진 section은 생략한다.
#               `type: "interlude"`를 쓰면 사진 대신 중간 글/전환 블록을 만든다.
# - `grid`    : 사진 section의 레이아웃 종류. 생략 시 `lead-two-wide`가 기본값이지만,
#               장수 실수를 막으려면 항상 명시하는 것을 권장한다.
# - `tone`    : 사진 section의 배경/분위기. 기본값은 `paper`.
# - `variant` : 일부 grid에만 있는 세부 배치 옵션.
#               trio / statement / lead-four / four-lead에서만 의미가 있다.
# - `order`   : 사진 순서 처리. 기본값은 `manual`.
#               현재 `auto`는 lead-two-wide / wide-two-lead에서만 동작한다.
# - `label`   : 선택. section 상단 메타에 표시되는 짧은 글자. 예: `JUL 13`, `MORNING`.
# - `photos`  : 이 section에 넣을 photo id 목록. grid가 요구하는 장수와 정확히 맞춘다.
#
# ---------------------------------------------------------------------------
# 1. photo_groups 옵션 — 여러 section을 하나의 챕터로 묶기
# ---------------------------------------------------------------------------
# `photo_groups`는 section의 `group`과 연결되는 챕터 정보다.
# 사용 가능한 키:
# - `id`       : 연결용 고유 id. section의 `group`과 동일해야 한다.
# - `tone`     : 챕터 박스 배경. section의 `tone`과는 별개다.
#                `paper` = 기본 밝은 종이색
#                `sand`  = 따뜻한 베이지/모래색
#                `sage`  = 잔잔한 세이지 그린
#                `sea`   = 차분한 블루/그레이
#                `dusk`  = 옅은 보라/회색
# - `eyebrow`  : 챕터 제목 위의 작은 텍스트. 예: `2025 · 07`
# - `title`    : 챕터의 큰 제목. 예: `JUL 13`
# - `subtitle` : 챕터 오른쪽 보조 설명. 예: `15:53–19:41 · 21 frames`
#
# 예)
#   photo_groups:
#     - id: "d0713"
#       tone: "sand"
#       eyebrow: "2025 · 07"
#       title: "JUL 13"
#       subtitle: "15:53–19:41 · 21 frames"
#
# ---------------------------------------------------------------------------
# 2. 중간 글 / 전환 블록 — type: "interlude"
# ---------------------------------------------------------------------------
# 사진 사이에 큰 문구를 넣고 싶을 때 사용한다. `photos`와 `grid`는 쓰지 않는다.
# 사용 가능한 키:
# - `type: "interlude"` : 필수. 이 section을 글 블록으로 전환한다.
# - `group`              : 선택. 같은 group을 주면 해당 챕터 내부에 들어간다.
# - `eyebrow`            : 작은 위쪽 문구. 생략 시 page.kicker → `PHOTO STORY` 순으로 fallback.
# - `title`              : 중앙 큰 문구. 생략 시 page.location → page.title 순으로 fallback.
# - `subtitle`           : 아래쪽 작은 문구. 생략 시 포스트 날짜를 `Month · Year` 형태로 표시한다.
# - `tone`               : 템플릿에서는 class를 만들지만, 현재 CSS는 interlude별 tone 차이를
#                          따로 정의하지 않아 실질적으로 동일한 dark 스타일로 보인다.
#                          의도를 명확히 하려면 `tone: "dark"`로 적어두면 된다.
#
# 예) 사진 섹션 사이에 제주 전환 문구 넣기
#   - type: "interlude"
#     group: "d0725"
#     tone: "dark"
#     eyebrow: "JEJU · SUMMER"
#     title: "A slow afternoon"
#     subtitle: "2025.07.25 · Jeju"
#
# ---------------------------------------------------------------------------
# 3. 사진 section tone 옵션
# ---------------------------------------------------------------------------
# 일반 사진 section에서 사용 가능한 tone:
# - `paper` : 기본. 별도 패널 없이 밝은 배경 위에 자연스럽게 배치.
# - `mist`  : 옅은 녹색/회색 패널. 조용하고 차분한 구간 전환에 적합.
# - `soft`  : 옅은 핑크/회색 패널. 조금 더 부드러운 분위기.
# - `dark`  : 짙은 어두운 패널. 밤 사진이나 강한 장면 전환에 적합.
# - `blend` : `grid: "pair"` 전용 특수 tone. 두 사진의 색을 크게 blur해 배경으로 섞는다.
#
# 주의: photo_groups의 `sand / sage / sea / dusk`는 그룹 배경용이고,
#       section의 `paper / mist / soft / dark / blend`와 역할이 다르다.
#
# ---------------------------------------------------------------------------
# 4. 1장 레이아웃
# ---------------------------------------------------------------------------
# [statement] — 사진 한 장을 집중해서 보여주는 세로 중심 레이아웃
# - 장수: 1장
# - `variant: "normal"` : 기본. 세로 사진을 비교적 작은 단독 프레임으로 중앙 배치.
# - `variant: "wide"`   : 같은 statement지만 넓은 wide renderer를 사용.
#                          landscape는 실제 가로 비율을 살리고, portrait는 blur 배경 + 중앙 원본.
# - variant 생략 시 `normal`.
#
# 예)
#   - grid: "statement"
#     tone: "paper"
#     variant: "normal"
#     photos: [p01]
#
# [wide] — 넓은 무대 한 장 전용
# - 장수: 1장
# - 별도 variant 없음.
# - landscape는 실제 원본 비율로 넓게 표시.
# - portrait는 넓은 blur 배경 안에 세로 원본을 중앙 배치.
#
# ---------------------------------------------------------------------------
# 5. 2장 레이아웃
# ---------------------------------------------------------------------------
# [pair]
# - 장수: 2장
# - 두 사진을 여백을 두고 나란히 배치하며 2번째 사진이 약간 아래로 내려간다.
# - 일반 배경은 `tone: "paper" / "mist" / "soft" / "dark"` 사용 가능.
# - `tone: "blend"`를 쓰면 두 사진을 좌/우에 두고 두 사진 색을 강하게 blur한
#   혼합 배경을 만든다. `blend`는 pair에서만 의미가 있는 특수 처리다.
#
# 예)
#   - grid: "pair"
#     tone: "blend"
#     photos: [p01, p02]
#
# ---------------------------------------------------------------------------
# 6. 3장 레이아웃
# ---------------------------------------------------------------------------
# [lead-two]
# - 장수: 3장
# - photos의 1번째가 왼쪽 큰 lead. 2/3번째가 오른쪽 위/아래 보조 사진.
# - variant 없음.
#
# [two-lead]
# - 장수: 3장
# - photos의 1번째가 오른쪽 큰 lead. 2/3번째가 왼쪽 위/아래 보조 사진.
# - 이름은 mirrored layout이지만 큰 사진은 여전히 photos의 1번째라는 점에 주의.
# - variant 없음.
#
# [trio]
# - 장수: 3장
# - 세 장의 크기는 동일하고 `variant`로 세로 위치 흐름을 정한다.
# - `variant: "line"`      : 01 / 02 / 03이 같은 높이. 기본값.
# - `variant: "wave-up"`   : 01 높음 → 02 중간 → 03 낮음.
#                              왼쪽에서 오른쪽으로 계단처럼 흘러내리는 배치.
# - `variant: "wave-down"` : 01 낮음 → 02 중간 → 03 높음.
#                              오른쪽으로 갈수록 올라가는 반대 방향 배치.
#
# 예)
#   - grid: "trio"
#     tone: "paper"
#     variant: "wave-up"
#     photos: [p01, p02, p03]
#
# ---------------------------------------------------------------------------
# 7. 4장 레이아웃 + order 옵션
# ---------------------------------------------------------------------------
# [lead-two-wide]
# - 장수: 4장
# - 1번째 = 왼쪽 큰 lead
# - 2/3번째 = 오른쪽 위의 보조 사진 2장
# - 4번째 = 오른쪽 아래 wide 슬롯
#
# [wide-two-lead]
# - 장수: 4장
# - 1번째 = 왼쪽 위 wide 슬롯
# - 2/3번째 = 왼쪽 아래의 보조 사진 2장
# - 4번째 = 오른쪽 큰 lead
#
# `order` 종류:
# - `order: "manual"` : 기본값. photos에 적은 순서를 그대로 유지.
# - `order: "auto"`   : 위 두 4장 grid에서만 지원.
#                        브라우저가 실제 이미지 naturalWidth / naturalHeight를 확인한다.
#                        현재 wide 슬롯이 portrait이고 같은 section 안에 landscape가 있으면,
#                        landscape 한 장과 wide 슬롯의 payload만 서로 swap한다.
#                        다른 사진들의 순서나 grid 구조는 바꾸지 않는다.
#                        landscape가 없으면 아무것도 바꾸지 않고 portrait-wide 처리를 사용한다.
#
# 즉 `auto`는 랜덤 정렬이 아니라 "wide 슬롯 하나를 위한 최소 swap"이다.
#
# 예)
#   - grid: "wide-two-lead"
#     tone: "paper"
#     order: "auto"
#     photos: [p01, p02, p03, p04]
#
# ---------------------------------------------------------------------------
# 8. 5장 레이아웃
# ---------------------------------------------------------------------------
# [lead-four]
# - 장수: 5장
# - 1번째 = 왼쪽 큰 프레임
# - 2/3/4/5번째 = 오른쪽 2x2 보조 프레임
#
# [four-lead]
# - 장수: 5장
# - 1/2/3/4번째 = 왼쪽 2x2 보조 프레임
# - 5번째 = 오른쪽 큰 프레임
#
# `variant` 종류:
# - `variant: "normal"` : 큰 슬롯을 일반 lead(세로 중심)로 렌더링. 기본값.
# - `variant: "wide"`   : 큰 슬롯을 기존 wide renderer로 렌더링.
#                          landscape를 큰 슬롯에 넣을 때 사용하면 원본 가로 비율을 살릴 수 있다.
#                          portrait를 넣어도 blur 배경 + 중앙 원본으로 정상 표시된다.
#
# 큰 슬롯 위치:
# - lead-four  = photos의 1번째
# - four-lead  = photos의 5번째
#
# 현재 5장 grid에는 `order: "auto"` 자동 swap이 없다.
# landscape를 크게 쓰려면 해당 사진 id를 큰 슬롯 위치로 직접 옮기고 `variant: "wide"`를 지정한다.
#
# 예) landscape p05를 오른쪽 큰 프레임으로 사용
#   - grid: "four-lead"
#     tone: "paper"
#     variant: "wide"
#     photos: [p01, p02, p03, p04, p05]
#
# ---------------------------------------------------------------------------
# 9. wide renderer 동작
# ---------------------------------------------------------------------------
# wide 역할을 받는 곳:
# - `grid: "wide"`
# - `statement + variant: "wide"`
# - lead-two-wide의 4번째 슬롯
# - wide-two-lead의 1번째 슬롯
# - lead-four + variant:"wide"의 1번째 슬롯
# - four-lead + variant:"wide"의 5번째 슬롯
#
# 표시 방식:
# - 실제 landscape: naturalWidth > naturalHeight이면 source ratio를 유지해 넓게 표시.
# - 실제 portrait : 넓은 blurred backdrop + 중앙 세로 원본 처리.
# 따라서 portrait가 wide 슬롯에 들어가도 오류가 아니며 자동으로 portrait-safe 방식이 적용된다.
#
# ---------------------------------------------------------------------------
# 10. 장수별 빠른 선택표
# ---------------------------------------------------------------------------
# - 1장: statement(normal/wide) / wide
# - 2장: pair (필요하면 tone: blend)
# - 3장: lead-two / two-lead / trio(line, wave-up, wave-down)
# - 4장: lead-two-wide / wide-two-lead (manual 또는 auto)
# - 5장: lead-four / four-lead (normal 또는 wide)
#
# 남는 장수 예:
# - 6장 = 3+3
# - 7장 = 4+3
# - 8장 = 5+3 또는 4+4
# - 9장 = 5+4
# - 10장 = 5+5
# landscape가 연속으로 여러 장이면 5장에 억지로 넣기보다 `wide`, 4장 wide grid, pair 등으로 나눠준다.
