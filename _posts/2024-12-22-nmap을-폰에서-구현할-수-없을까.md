### **앱 개발의 시작: nmap을 폰에서 구현할 수 있을까?**  
"네트워크 점검이 필요할 때, 자주 사용하는 툴은 단연 **nmap**이었다. 하지만 PC 없이 스마트폰에서 이런 강력한 도구를 구현할 수 있을까?"  

이 궁금증이 이번 프로젝트의 시작점이었다.  
- 스마트폰은 항상 가지고 다니는 기기이기 때문에 네트워크 점검이 가능하다면 훨씬 편리할 것 같았다.  
- 더 나아가, 단순 스캔 기능에서 그치지 않고 탐지된 서비스와 취약점(CVE)을 연계한 분석 기능까지 제공하면 어떨까?  
이러한 생각을 바탕으로 프로젝트 아이디어를 구체화하기 시작했다.

---

### **초기 테스트: Termux에서 nmap 돌려보기**  
우선, nmap을 스마트폰에서 실행할 수 있는지 간단히 테스트해 보았다.  
1. **Termux 설치**  
   - 루트 권한 없이 Termux 환경을 설치하고, nmap을 실행할 수 있는지 확인.  

2. **테스트 진행**
    - nmap을 `pkg install nmap` 으로 설치 후 nmap 명령어 테스트
    - Connect scan 사용
    ``` nmap -sT scanme.nmap.org```

3. **테스트 결과**  
   - **Wi-Fi 네트워크**와 **모바일 데이터** 모두에서 정상적으로 작동했다.  
   - [스크린샷: Termux에서 nmap 실행 결과 이미지 첨부]  

4. **한계 확인**  
   - UDP 스캔 기능은 루트 권한이 필요하다는 점을 발견.  
   - 따라서, 앱 개발에서는 UDP 스캔 기능을 제외하기로 결정했다.  

---

### **기능 구상: 더 나아가 보안 분석까지**  
Termux 테스트를 통해 nmap의 주요 기능을 구현할 수 있다는 가능성을 확인한 뒤, 앱에서 제공할 주요 기능을 구체화했다:  
1. **네트워크 스캔**:  
   - IP 주소와 MAC 주소 탐지  
   - 열린 포트와 서비스 탐지  

2. **서비스 탐지**:  
   - 포트에서 동작 중인 서비스와 버전 정보 표시  

3. **CVE 연계 분석**:  
   - 탐지된 서비스의 버전에 따라 CVE 데이터를 검색하고 관련 취약점을 제공.  
   - 예: Apache 2.4.49가 탐지되면 해당 버전의 CVE 정보를 표시.  

4. **스텔스 스캔**:  
   - **루트 권한 없이 스텔스 스캔 구현**  
     - TCP Connect 스캔을 응용해 매우 적은 타임아웃및 예외로 SYN 스캔과 유사하게 구현 루트 권한 없이 동작.  
     - 침투 테스트 환경에서도 탐지 가능성을 낮출수 있나? (검증이 필요함)  

5. **사용자 맞춤형 스캔 옵션**:  
   - **정확성 우선 모드**: 속도를 낮추고 데이터를 세밀히 수집.  
   - **속도 우선 모드**: 정확성을 줄이고 스캔 속도를 높임.  
   - **커스텀 모드**: 여러 환경 변수 값을 사용자가 입력하여 커스텀화.

---

### **스텔스 스캔의 설계 과정**  
스텔스 스캔은 단순한 스캔 기능 이상의 정교한 설계가 필요하다:  

#### **1. 스캔 기법**  
- **TCP SYN 스캔 (비 루트 권한 Connect로 구현)**: 
  - TCP SYN 스캔은 ROW 패킷을 생성을 할 수 있는 루트권한이 필요하기 때문에 
  - 포트가 열려 있는지 확인하기 위해 SYN 패킷만 전송.  
  - 중간에 타임아웃을 설정해 응답이 느릴 경우 스캔을 종료.  
  - 예외 상황(예: 네트워크 장애, 특정 IP 블록)에서 스캔을 자동으로 중단하는 메커니즘 추가.  

- **루트 권한 없이 실행 가능하도록 최적화**:  
  - Android API를 활용해 네트워크 접근 권한만으로 실행.  

#### **2. UI 설계**  
- **스캔 속도와 정확성을 조절할 수 있는 슬라이더 제공**:  
  - 사용자 선택에 따라 패킷 전송 간격 및 타임아웃 값을 동적으로 조정.  
  - “정확성 우선”과 “속도 우선” 옵션을 직관적으로 선택 가능.  

#### **3. 결과 분석 및 출력**  
- **탐지된 포트와 서비스 정보를 직관적으로 표시**:  
  - IP 주소별로 정리된 포트 상태, 서비스 버전 정보 제공.  
- **CVE 데이터베이스와 연계해 취약점 표시**:  
  - 탐지된 서비스와 관련된 취약점을 스캔 결과에 바로 표시.  
  - 클릭 시 CVE 세부 정보와 개선 방안 제공.  
- **여러 파일 형식 내보내기**
  - 클립보드
  - execl
  - txt
  - json
  - csv

### **결론과 도전 과제**  
이번 프로젝트는 단순히 nmap의 기능을 스마트폰에 옮기는 데서 그치지 않는다.  
- **스마트폰에 최적화된 사용자 경험**: 루트 권한 없이 네트워크를 스캔하고 분석할 수 있는 도구.  
- **보안 전문가도 활용 가능한 수준의 기능성**: 스텔스 스캔과 CVE 연계 분석을 포함.  

**도전 과제**:  
- 루트 권한 없이 스텔스 스캔 구현 시 정확도와 속도 간의 균형을 맞추는 것.  
- 다양한 네트워크 환경에서도 안정적으로 동작하도록 최적화.
