# ======================================================================
# PHOTO LAYOUT AUTHORING GUIDE
# ======================================================================
#
# 기본 원칙
# - `photos`는 사진 라이브러리다. ID는 가능하면 고정하고 여기서 순서를 바꾸지 않는다.
# - 실제 스토리 순서와 배치는 아래 `photo_sections`에서 사진 ID를 조합해서 정한다.
# - `group`은 같은 장소/날짜/테마를 하나의 큰 챕터 배경으로 묶는다.
# - `grid`는 한 섹션 안에서 사진이 놓이는 틀을 정한다.
# - `tone`은 해당 composition 하나의 배경/분위기다.
# - `variant`는 같은 grid의 모양 변형이다. 필요한 grid에서만 쓴다.
# - `order`는 4장 wide grid에서만 쓰는 선택 옵션이다. 지정하지 않으면 `manual`이다.
#
# ----------------------------------------------------------------------
# GROUP / CHAPTER
# ----------------------------------------------------------------------
# 같은 장소나 같은 테마의 여러 composition에 같은 `group` ID를 넣으면
# 하나의 큰 배경 블록 안에 같이 묶인다. 그룹 배경은 사진보다 튀지 않게 약하게 쓴다.
#
# group tone 추천:
#   paper : 가장 중립적인 기본 배경
#   sand  : 따뜻한 베이지 / 햇빛 / 카페 / 오후
#   sage  : 옅은 녹색 / 숲 / 자연
#   sea   : 옅은 블루그레이 / 바다 / 하늘
#   dusk  : 옅은 모브 / 저녁 / 야간 전환
#
# ----------------------------------------------------------------------
# 4 PHOTOS
# ----------------------------------------------------------------------
# 1) lead-two-wide
#    photos: [p01, p02, p03, p04]
#
#    +--------------+ +------+ +------+
#    |              | |  02  | |  03  |
#    |   01 LEAD    | +------+ +------+
#    |              | +---------------+
#    +--------------+ |    04 WIDE    |
#                     +---------------+
#
#    기본(manual): 01=lead, 02/03=support, 04=wide.
#
# 2) wide-two-lead
#    photos: [p01, p02, p03, p04]
#
#    +---------------+ +--------------+
#    |    01 WIDE    | |              |
#    +-------+-------+ |   04 LEAD    |
#    |  02   |  03   | |              |
#    +-------+-------+ +--------------+
#
#    기본(manual): 01=wide, 02/03=support, 04=lead.
#
# `order: "auto"` (위 두 4장 grid에서만 사용)
# - 지정하지 않으면 사진 순서를 절대 바꾸지 않는다.
# - auto를 쓰면 브라우저가 실제 이미지 비율을 확인한다.
# - 현재 wide 슬롯이 이미 가로 사진이면 그대로 둔다.
# - wide 슬롯이 세로인데 다른 3장 중 가로 사진이 있으면 그 사진과 wide 사진만 교환한다.
# - 가로 사진이 하나도 없으면 원래 순서를 유지한다.
# - 즉 전체 순서를 랜덤하게 섞는 옵션이 아니라, wide 자리에 가로 사진을 우선 배치하는 옵션이다.
#
# 예:
#   - grid: "lead-two-wide"
#     order: "auto"
#     photos: [p01, p02, p03, p04]
#
# ----------------------------------------------------------------------
# 3 PHOTOS
# ----------------------------------------------------------------------
# 1) lead-two
#    photos: [p01, p02, p03]
#
#    +--------------+   +--------+
#    |              |   |   02   |
#    |   01 LEAD    |   +--------+
#    |              |   |   03   |
#    +--------------+   +--------+
#
#    01은 왼쪽 큰 사진.
#    02/03 두 장의 묶음 전체가 01의 세로 중앙을 기준으로 정렬된다.
#
# 2) two-lead
#    photos: [p01, p02, p03]
#
#    +--------+   +--------------+
#    |   02   |   |              |
#    +--------+   |   01 LEAD    |
#    |   03   |   |              |
#    +--------+   +--------------+
#
#    여기서도 01이 항상 lead다. 좌우 위치만 반전된다.
#    02/03 두 장의 묶음 전체가 01의 세로 중앙에 맞는다.
#
# 3) trio
#    세 장의 크기는 동일하고 `variant`로 세로 리듬만 선택한다.
#    variant를 생략하면 `line`이 기본값이다.
#
#    variant: "line"
#    +------+ +------+ +------+
#    |  01  | |  02  | |  03  |
#    +------+ +------+ +------+
#
#    variant: "wave-up"
#    +------+
#    |  01  |   +------+
#    +------+   |  02  |   +------+
#               +------+   |  03  |
#                          +------+
#    01 위 -> 02 중간 -> 03 아래.
#
#    variant: "wave-down"
#                          +------+
#               +------+   |  03  |
#    +------+   |  02  |   +------+
#    |  01  |   +------+
#    +------+
#    03 위 -> 02 중간 -> 01 아래.
#
# 예:
#   - grid: "trio"
#     variant: "wave-up"
#     photos: [p20, p21, p22]
#
# ----------------------------------------------------------------------
# 2 PHOTOS
# ----------------------------------------------------------------------
# pair
# - 두 사진을 여백 있게 나란히 보여주는 조용한 연결용 레이아웃.
# - `tone: "blend"`는 pair 전용 특수 톤으로 쓰는 것을 권장한다.
# - blend는 두 사진을 좌/우 배경에 크게 깔고 강한 blur + 중앙 fade로 섞는다.
# - 실제 앞쪽 사진 두 장은 선명하게 유지된다.
#
# 예:
#   - grid: "pair"
#     tone: "blend"
#     photos: [p05, p06]
#
# ----------------------------------------------------------------------
# 1 PHOTO
# ----------------------------------------------------------------------
# 1) statement
# - 대표 컷 / 챕터 핵심 컷처럼 사진 한 장에 강하게 집중할 때 사용한다.
# - variant 생략 시 `normal`.
#
#   variant: "normal"
#   세로 3:4 프레임을 크게 중앙에 보여준다.
#
#   variant: "wide"
#   statement의 강조 강도는 유지하면서 가로 무대로 확장한다.
#   가로 원본이면 실제 가로 비율을 그대로 크게 보여준다.
#   세로 원본이면 wide 규칙과 동일하게 blur 배경 + 중앙 강조를 사용한다.
#
# 예:
#   - grid: "statement"
#     variant: "wide"
#     tone: "dark"
#     photos: [p45]
#
# 2) wide
# - 한 장을 가로형 visual stage로 보여준다.
# - 이미지 방향은 자동 판별한다. 별도 orientation 값을 적을 필요 없다.
# - 가로 사진: 원본 가로 비율을 유지하고 직접 크게 표시.
# - 세로 사진: 가로 stage + 같은 사진의 blur 배경 + 중앙 crop/강조.
#
# ----------------------------------------------------------------------
# TONE (composition 단위)
# ----------------------------------------------------------------------
# paper : 기본. 가장 많이 사용한다.
# mist  : 옅은 그린/그레이 계열의 작은 분위기 전환.
# soft  : 옅은 모브 계열의 작은 분위기 전환.
# dark  : 정말 강조할 사진이나 분위기 전환에만 제한적으로 사용.
# blend : pair에서 두 사진의 색을 섞은 강한 blur 배경. pair 사용 권장.
#
# 주의: group tone과 section tone을 둘 다 강하게 바꾸면 산만해질 수 있다.
# 보통 group이 이미 색을 갖고 있으면 section은 `paper` 위주로 두고,
# statement / pair 같은 특별한 구간에서만 `dark`, `mist`, `blend`를 쓴다.
#
# ----------------------------------------------------------------------
# QUICK CHOICE
# ----------------------------------------------------------------------
# 4장 + 대표/가로 포함        -> lead-two-wide / wide-two-lead
# 4장 + 가로를 알아서 찾기   -> 위 grid + order: "auto"
# 3장 + 한 장이 중요          -> lead-two / two-lead
# 3장 + 균등하고 정돈         -> trio + line
# 3장 + 흐름/움직임           -> trio + wave-up / wave-down
# 2장 + 조용한 연결           -> pair
# 2장 + 색감 자체를 묶기      -> pair + tone: "blend"
# 1장 + 대표 세로 컷          -> statement (normal)
# 1장 + 대표 컷을 가로 강조   -> statement + variant: "wide"
# 1장 + 단순 가로 무대        -> wide
#
# ======================================================================
